\section{Experimental Design}

Each experiment must be represented by a frozen configuration and a run directory under \texttt{paper/experiments/results/runs/}. The minimum record includes the source-code commit, data version, environment, exact command, random seed when applicable, model identifiers, metrics, and a note describing failures or deviations.

The planned evaluation should include at least: retrieval acceptance on governed literature, evidence and citation correctness, refusal or insufficient-evidence behavior, robustness to conflicting evidence and service failures, and downstream pedestrian-flow analysis on datasets with an explicit ground-truth boundary. Baselines and acceptance thresholds must be defined before inspecting final test results.

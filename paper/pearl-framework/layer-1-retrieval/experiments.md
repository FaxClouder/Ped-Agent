# Layer 1 实验设计

*Retrieval 层对照实验的变量、流程与报告结构 · status: plan · 2026-09-28*

> 本文把 [design.md](design.md) §6 的三组对照扩展为带变量声明的实验设计，指标定义见 [metrics.md](metrics.md)，统计方法见 [statistical-methods.md](statistical-methods.md)。本文是设计记录，不表示实验已运行。

## 1. 研究问题

| 编号 | 问题 | 对应实验 |
| --- | --- | --- |
| RQ1.1 | 中文查询检索英文语料时，稠密向量相比词法检索的优势有多大？ | E1 vs. E3 |
| RQ1.2 | 词法检索的劣势中，多少来自跨语言、多少来自方法本身？ | E1 vs. E2 |
| RQ1.3 | RRF 融合能否超过单一最优方法？ | E4 vs. max(E2, E3) |
| RQ1.4 | 检索方法对查询语言的敏感度是否不同？ | E5 双语对照 |
| RQ1.5 | 不同题型的检索难度差异？ | 分层分析 |

RQ1.2 是本层的独有问题：当前语料 104 篇全为 `language='en'`，Stage 2 查询为中英双语。词法通道在中文侧结构性失效，若不隔离语言因素，BM25 的低分会被误读为"稀疏检索不适用本领域"。

## 2. 实验变量

### 2.1 自变量

**IV1 检索方法**（被试内，5 水平）

| 水平 | 配置 | 说明 |
| --- | --- | --- |
| E1 | BM25，jieba 分词，中文查询 | 跨语言失配基线 |
| E2 | BM25，英文分词，查询译为英文 | 词法检索上界 |
| E3 | BGE-M3 dense，中文查询 | 多语言稠密向量 |
| E4 | RRF(E2, E3)，沿用现有 `rrf_k=60` | 混合融合 |
| E5 | BGE-M3 dense，中英查询各一次 | 语言敏感度探针 |

**IV2 查询语言**（被试内，2 水平）：`zh`、`en`，取自 Stage 2 的 `queries` 字段。仅 E5 及 §6.3 的语言分析使用。

**IV3 题型**（被试间，事后分层）：取自标注的 `primary_topic` 与问题性质，见 §6.2。

### 2.2 因变量

主：Page-Hit@10。辅：Page-Coverage@10、Page-MRR@10。诊断：Resource-Hit@10、正确页首次出现排名。

### 2.3 控制变量

| 项目 | 固定值 |
| --- | --- |
| 解析器 | `adobe-pdf-extract-v1` |
| 切块策略 | `parent-child-v1` |
| 检索单元 | child chunk |
| 截断深度 | $K = 10$ |
| 重排 | 无 |
| 索引 | `memPed/knowledge/knowledge.sqlite3`，记录 fingerprint |
| 标签 | 单一版本，所有方法共享 |
| RRF 候选深度与参数 | 沿用现有配置并记录，不做参数搜索 |

**解析器纯净性核查**：索引中 102 个资源用 `adobe-pdf-extract-v1`，2 个用 `pymupdf-structured-v2`（`lit-10-1016-j-trc-2024-104762`、`lit-10-1016-j-trc-2024-104763`）。后者之一（`...104763`）在 Stage 2 标注来源中。运行前须确认该题是否保留：保留则在结果中标注解析器混合，移除则可计分题数降至 17。

## 3. 实验设计类型

**重复测量设计**：每个 intent 在全部检索方法上运行，消除 intent 难度差异带来的混淆。分析采用配对检验，不用独立样本检验。

**单位**：underlying intent。中英查询按 [metrics.md](metrics.md) §8 先内部取均值。

## 4. 样本

| 项目 | 数量 |
| --- | --- |
| Stage 2 intent 总数 | 20 |
| 可计分 intent | 18 |
| 排除 | `rgq-015`、`rgq-122`（`required_facts` 为空） |
| 双语查询条数 | 36（18 × 2） |
| 涉及资源 | 12 |

$N = 18$ 属探索性规模。样本量对结论的约束见 [statistical-methods.md](statistical-methods.md) §5。

## 5. 实验流程

对每个可计分 intent $q$ 和每个方法 $m$：

1. 取查询文本。E2 需先将中文查询译为英文，记录翻译模型与提示版本，译文随结果一并保存。
2. 检索 Top-10 child chunks，保存排名、chunk ID、分数、来源资源、`page_start`/`page_end`、`parent_chunk_id`。
3. 按 [metrics.md](metrics.md) §4 计算页级指标，按 §3 计算资源级诊断指标。
4. 记录正确页首次出现排名（含 >10 的情形，用于失败归因）。

**产出**：
- 逐题命中记录（每 intent × 方法一行，含各指标与完整排序）
- 主表汇总
- 失败案例清单，按 [failure-taxonomy.md](failure-taxonomy.md) 归类

**可复现信息**：输入哈希、标签版本、代码版本、索引 fingerprint、模型版本、检索配置、随机种子（如适用）。结果写入 `outputs/` 下独立命名目录，不覆盖已有输出。

## 6. 报告结构

### 6.1 主表

| 方法 | Page-Hit@10 | Page-Coverage@10 | Page-MRR@10 | Resource-Hit@10 |
| --- | --- | --- | --- | --- |
| E1 BM25 (jieba, zh) | 待运行 | 待运行 | 待运行 | 待运行 |
| E2 BM25 (en, 译文) | 待运行 | 待运行 | 待运行 | 待运行 |
| E3 BGE-M3 | 待运行 | 待运行 | 待运行 | 待运行 |
| E4 RRF(E2, E3) | 待运行 | 待运行 | 待运行 | 待运行 |

每格报均值与 bootstrap 95% CI。Page-Coverage 列须附注"当前标注下与 Page-Hit 恒等"。

比较时优先看 Page-Hit@10，以 Page-MRR@10 解释排序差异，以 Resource-Hit@10 定位失败层级。

### 6.2 分层表

按题型分层报告 Page-Hit@10。分层依据取自标注字段与问题性质：

| 分层维度 | 水平 | 来源 |
| --- | --- | --- |
| 事实性质 | 定性 / 定量 / 比较 / 条件 | 人工审查 `required_facts` 文本 |
| 主题 | `primary_topic` 各取值 | 标注字段 |
| 标注页位置 | 第 1 页 / 正文页 | `pdf_page_1based` |

**标注页位置分层是必报项**：15/18 题标注页为第 1 页，须单独报告正文页子集（$N = 3$）的结果，说明摘要页集中对总体数值的影响。$N = 3$ 仅作描述，不做检验。

分层后各层样本量为 3–12，只报描述统计。

### 6.3 语言效应

对 E5 的中英查询结果，报告：

- 各语言的 Page-Hit@10
- **双语一致率**：同一 intent 中英查询 Page-Hit 取值相同的比例
- 不一致案例清单及其方向（仅中文命中 / 仅英文命中）

E1 与 E2 的差值提供另一条语言效应证据：两者检索方法同为 BM25，差异仅在查询语言与分词器，因此 $\Delta = \mathrm{E2} - \mathrm{E1}$ 可归因于跨语言失配。

### 6.4 失败分析

按 [failure-taxonomy.md](failure-taxonomy.md) 对每个 Page-Hit@10 = 0 的案例归类，报告各类别计数，并对 3–5 个典型案例做深度分析。另选 2–3 个全方法命中的案例作为对照，说明检索能力上界。

## 7. 预期结果与判读

以下是基于 2026-09-21 既有实测（FTS-only recall@5 = 0.48，31 题中 11 题零命中；加入 BGE-M3 后 recall@5 = 0.94、MRR = 0.77）的先验预期，写在此处以便区分"预期确认"与"新发现"：

| 预期 | 依据 |
| --- | --- |
| E1 显著低于 E3 | 中文分词无法匹配英文词形 |
| E2 高于 E1 | 隔离语言因素后词法检索恢复部分能力 |
| E4 接近或略高于 E3 | 融合受益于 E2 的词法信号 |
| E5 双语一致率高 | 多语言向量对查询语言不敏感 |

E1 低分是**设计上可预期的结构性结果**，不是实验发现。报告须如此表述，不能写成"实验表明稀疏检索不适用于本领域"。

若 E2 仍显著低于 E3，才构成"该语料上词法检索弱于稠密检索"的证据；若 E2 接近 E3，则 E1 的低分应完全归因于跨语言失配。

## 8. 本轮不做

- 解析 × 切块 × 模型的组合网格
- 干扰注入与鲁棒性压力测试
- 生成器对照与端到端答案评测
- 多轮 Agent 消融
- RRF 参数搜索
- 多个 $K$ 的主报告

重排确有需要且模型资产可用时追加一组，触发条件：E3 与 E2 差距小于 0.15，或 E4 未超过单一最优方法，或 Page-Hit@10 整体低于 0.60。

## 9. 与后续层级的衔接

开发集结果用于选择后续候选检索底座，不声称封存测试结论。选定配置后固定其检索器，供 Layer 1.5 及以上层级使用，见 [PEARL-framework.md](../PEARL-framework.md) §2.1 的层间接口约定。

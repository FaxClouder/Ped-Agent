# Layer 1 统计方法

*小样本重复测量设计下的估计、检验与报告规约 · status: plan · 2026-09-28*

> 适用于 [experiments.md](experiments.md) 定义的对照实验。$N = 18$ 可计分 intent，4–5 个方法被试内比较。本文规定的方法在实验运行前写定，运行后不再调整。

## 1. 分析单位

统计单位是 underlying intent，$N = 18$。同一 intent 的中英查询变体先按 [metrics.md](metrics.md) §8 取均值，再进入 intent 层统计。**不把 36 条查询当作 36 个独立样本**——这会把有效样本量虚报一倍，并低估标准误。

Bootstrap 重采样与配对检验同样以 intent 为单位聚类。

## 2. 描述统计

**点估计**：题集宏平均 $\hat{\mu}$。

**标准误**：$\mathrm{SE} = s / \sqrt{N}$，其中 $s$ 是 intent 层得分的样本标准差。

对 Page-Hit@10 这类二值指标，intent 层得分取值为 $\{0, 1\}$（双语取均值后可为 $0.5$），$\mathrm{SE}$ 按实际得分向量计算，不用二项分布近似——双语均值破坏了伯努利假设。

## 3. 区间估计

**方法**：非参数 bootstrap，按 intent 重采样。

| 参数 | 值 |
| --- | --- |
| 重采样次数 | $B = 10000$ |
| 重采样单位 | intent（整条记录，保留其全部方法的得分） |
| 区间类型 | 百分位法，2.5% / 97.5% |
| 随机种子 | 固定并记录 |

**按 intent 整体重采样**是关键：同一次重采样中，所有方法使用同一批 intent，保留方法间的配对结构，使方法差值的 CI 也可由同一过程得到。

差值的 CI 由每次重采样内计算 $\Delta_b = \hat{\mu}_{m_1, b} - \hat{\mu}_{m_2, b}$ 得到，不由两个独立 CI 相减。

$N = 18$ 时 bootstrap CI 宽度约 $\pm 0.15$–$0.25$（对中等水平的比例指标），报告须如实呈现该宽度。

## 4. 假设检验

**检验方法**：Wilcoxon signed-rank test（配对，非参数）。

| 项目 | 设定 |
| --- | --- |
| 零假设 | 两方法在同一 intent 上的得分分布无系统差异 |
| 备择假设 | 双侧 |
| 显著性水平 | $\alpha = 0.05$ |
| 配对方式 | 按 intent |

选非参数检验的理由：$N = 18$ 且 Page-Hit 为二值/三值取值，正态性假设不成立，配对 $t$ 检验不适用。

**二值指标的补充检验**：Page-Hit@10 在单语汇总下为严格二值时，可用 McNemar 检验（精确版本，$N$ 小）。双语取均值产生 $0.5$ 时退回 Wilcoxon。实际采用哪一种按数据分布确定并记录。

### 4.1 效应量

配对 Cohen's $d$：

$$
d = \frac{\bar{\Delta}}{s_{\Delta}}
$$

其中 $\bar{\Delta}$ 和 $s_\Delta$ 是 intent 层差值的均值与标准差。

判读：$|d| < 0.3$ 小，$0.3$–$0.8$ 中，$> 0.8$ 大。

**效应量与 $p$ 值同报**。$N = 18$ 下中等效应难以达到显著，只报 $p$ 值会把"样本量不足"误读为"无差异"。

### 4.2 多重比较

4 个主要方法产生 $\binom{4}{2} = 6$ 个成对比较。

**校正**：Holm–Bonferroni（比 Bonferroni 更不保守，仍控制 family-wise error rate）。

报告原始 $p$ 值与校正后判断两列，不只报校正后结果。

**预先声明的主要比较**：E1 vs. E3（RQ1.1）、E1 vs. E2（RQ1.2）、E4 vs. E3（RQ1.3）。其余比较为探索性，单独标注。

## 5. 小样本约束

$N = 18$ 对结论强度的限制：

| 项目 | 约束 |
| --- | --- |
| 可检出效应 | 仅大效应（$d > 0.8$）有合理检出力 |
| CI 宽度 | 比例指标约 $\pm 0.15$–$0.25$ |
| 分层分析 | 各层 $N = 3$–$12$，只报描述统计，不做检验 |
| 单题影响 | 每题占总分 $1/18 \approx 5.6$ 个百分点 |

**所有主表与分层表加脚注**：

> $N = 18$ 可计分 intent，探索性结果。置信区间较宽，单题变动影响约 5.6 个百分点。结论需在更大样本上验证。

不在 $N = 18$ 上声明"某方法优于另一方法"，除非差值 CI 不含 0 且效应量为大。

## 6. 敏感性分析

### 6.1 Leave-one-out

逐个移除 intent，重新计算主要比较的方向与显著性。报告：

- 主要结论在 $x/18$ 种 leave-one-out 情形下保持
- 移除后结论翻转的 intent（"关键样本"）及其特征

任一单题能翻转结论时，该结论须降级为"提示性"。

### 6.2 标注页位置子集

15/18 题标注页为第 1 页。须另报正文页子集（$N = 3$）的描述统计，并说明若正文页比例提高，总体数值预期下降的方向。

### 6.3 映射规则敏感性

页级宽松映射（[metrics.md](metrics.md) §4.1）是可替换的设计选择。条件允许时，另按较严规则重算一次，报告结论是否随映射规则改变：

| 规则 | 定义 |
| --- | --- |
| 宽松（默认） | 覆盖标注页的任意 child chunk |
| 收紧 | 覆盖标注页且 token 数高于该页中位数的 chunk |

两种规则下结论一致，才说明结果对映射选择稳健。

### 6.4 争议题纳入

2 个 `agent_disputed` 题当前因 `required_facts` 为空不可计分。若后续补齐其必要信息，须同时报告 $N = 18$ 与 $N = 20$ 两套结果，不用纳入与否择优呈现。

## 7. 报告清单

每个实验结果须包含：

- 各方法的 $\hat{\mu}$、$\mathrm{SE}$、bootstrap 95% CI
- 预先声明的成对比较：$\bar{\Delta}$、差值 CI、原始 $p$、Holm 校正判断、Cohen's $d$
- 可计分 intent 数与查询数
- leave-one-out 稳健性结论
- 小样本脚注
- bootstrap 种子与重采样次数

## 8. 不做的事

- 不对分层子集（$N < 15$）做假设检验
- 不用未校正的 $p$ 值声明多个比较均显著
- 不把 36 条查询当独立样本以获得更窄的 CI
- 不在看到结果后更改检验方法、$\alpha$ 或主要比较清单
- 不设置无研究依据的通过阈值
- 不用 $p > 0.05$ 声明"两方法等效"（等效性需另设检验与界值）

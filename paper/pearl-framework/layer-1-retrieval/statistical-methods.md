# Layer 1 统计分析协议

*英文 Retrieval 新实验的配对分析与不确定性报告 · status: plan · protocol v0.2 · 2026-09-29*

本文配套 [指标协议](metrics.md) 与 [实验设计](experiments.md)。计划新建 80 个开发 intent 和 200 个独立评估 intent；这些数字是采样目标，不代表数据已建成、模型已运行或检验功效已经达到要求。旧题集、标签和结果均不参与分析。

## 1. 分析单位与目标量

每个 intent 使用一条预先冻结的英文规范查询，并在全部可运行方法上配对评价。同一意图的英文改写、重复运行和多个证据组均不增加样本量；若另做改写实验，须保留 intent 聚类且另列结果。

| 互斥主层 | 开发集目标 | 评估集目标 |
| --- | --- | --- |
| 单事实 | 20 | 50 |
| 数值／表格 | 20 | 50 |
| 单篇多证据 | 20 | 50 |
| 跨篇比较／条件／冲突 | 20 | 50 |
| 合计 | 80 | 200 |

每题只进入一个主层；多种证据路线、表格、条件依赖等交叉标签可用于描述，但不重复计入总体。互斥归类规则须在抽样前冻结。

对方法 $m$，主分析目标为冻结题集上按 intent 宏平均的完整证据组成功率。令 $N=\sum_{h=1}^{4}N_h$，各主层权重为冻结样本占比 $w_h=N_h/N$：

$$
\widehat{\mu}_m=\frac{1}{N}\sum_{i=1}^{N}Y_{im}
=\sum_{h=1}^{4}\frac{N_h}{N}\frac{1}{N_h}\sum_{i\in h}Y_{im},
\qquad Y_{im}=\mathrm{CEGR}_{im}@10\in\{0,1\}.
$$

当前计划每层 $N_h=50$、共 200 个评估 intent，因此四层权重恰好各为 $1/4$；等权是当前配额的结果，不是独立于样本构成的加权规则。主结果描述预先声明的题型构成，不自动代表现实用户查询的题型频率。若语料条件要求不等配额，必须在独立评估运行前修订并登记题型分布、实际 $N_h$、总样本数和协议版本；此后使用冻结的 $N_h/N$，不能根据成绩删题、补题或调整权重。

开发集用于试运行、排错、参数选择和标注改进；独立评估集在配置冻结后一次性评价。两者分别成表，不合并成 $N=280$ 的验证结果。评估集不得参与选择模型、RRF 参数、重排预算、阈值或主比较。

## 2. 指标分工

| 指标 | 角色 | 主要报告 |
| --- | --- | --- |
| CEGR@10 | 唯一主指标；逐 intent 严格二值 | 成功数／总数、率、95% CI；主比较的配对差值与检验 |
| BestGroupCov@10 | 次指标；部分证据覆盖，取值在 $[0,1]$ | 宏平均、配对均值差、95% CI |
| CompleteMRR@10 | 排序诊断；完整证据组首次形成的位置 | 宏平均及 95% CI |
| $K=1,5,20$ 的同口径结果 | 截断敏感性诊断 | 曲线或附表；不择优替换 $K=10$ |

CEGR 的组内 AND、替代组之间 OR，以及原始 child 内容的命中规则见 [metrics.md](metrics.md)。本文不因检索器变化修改这些定义。深度 $D=100$ 的阶段候选记录用于失败定位；未在此深度观察到证据不等于语料中不存在证据。

## 3. 预先固定的主要比较

方法编号以 [experiments.md](experiments.md) 为准：R1 为 BM25，R2 为 BGE-M3 dense，R3 为 RRF hybrid，R4 为对同一 R3 候选池重排。三项比较共同构成一个主检验族：

| 比较 | 差值方向 | 回答的问题 |
| --- | --- | --- |
| C1 | R2 − R1 | 该英文语料与题集上的 dense 与词法检索差异 |
| C2 | R3 − R2 | 加入词法通道与融合后的增量 |
| C3 | R4 − R3 | 固定候选池上的重排增量 |

R3 − R1 另报配对差值与描述性 CI，但不在本版协议中构成第四项确证性主张。若要声称 R3 优于两个单路基线，须在看评估结果前修订比较族和检验方案，不能用开发或评估集中的“最佳单路方法”动态替代对照。

三项检验均为双侧，族错误率目标 $\alpha=0.05$，使用 Holm 逐步校正，并同时给出原始与调整后 $p$ 值。选择 `holm`，而不是库的默认校正方法；方法定义见 [statsmodels 多重检验文档](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html)。

若 R4 因模型或运行条件缺失未执行，C3 显示“未运行”，其调整输入占位为 $p=1$，仍保留三项比较族。该占位不是测得的 $p$ 值，也不表示 R4 与 R3 相同。其他未运行主比较同样处理，不在看结果后缩小比较族。

## 4. 二值主指标的检验与效应

对任一比较 $A-B$，用同一批评估 intent 的二值结果构造配对表：

|  | B 成功 | B 失败 |
| --- | --- | --- |
| A 成功 | $a$ | $b$：A 独有成功 |
| A 失败 | $c$：B 独有成功 | $d$ |

配对成功率差为 $\widehat{\Delta}=(b-c)/N$；乘以 100 后报告为百分点。主效应报告原始差值、配对 CI、$b$ 与 $c$，不依赖标准化效应量或通用“大／中／小”阈值。

检验固定使用双侧精确 McNemar：在零假设下，不一致配对的两种方向等概率，$b\mid(b+c)\sim\operatorname{Binomial}(b+c,0.5)$。$b+c=0$ 时记 $p=1$，解释为本批意图没有观察到不同结果，不解释为等效。精确二项版本及其与大样本近似的区别见 [statsmodels McNemar 文档](https://www.statsmodels.org/stable/generated/statsmodels.stats.contingency_tables.mcnemar.html)。

该检验需要 intent 间的独立性及零假设下不一致方向的对称性；固定分层中各类效果相反时，应同时呈现分层方向，不能用总体结果声称每类题都获益。显著性结论使用 Holm 调整后的 $p$，不能以未校正的差值 CI 是否跨 0 替代族内检验。$p>0.05$ 不构成等效性证据。

## 5. 配对分层 bootstrap 区间

所有主表指标均报告下列近似区间；方法间差值使用同一套重采样索引：

| 参数 | 预定值 |
| --- | --- |
| 重采样次数 | 10,000 |
| 随机种子 | 20260929 |
| 重采样单元 | 整个 intent 向量，包含其全部方法和指标 |
| 分层规则 | 每个主层内有放回抽取原层样本数；评估集计划每层 50 |
| 总体权重 | 冻结题集的各层占比 $N_h/N$；当前每层 50、共 200 时各为 $1/4$ |
| 区间 | bootstrap 分布的第 2.5 与第 97.5 百分位 |

每轮先抽 intent，再对各方法计算总体均值和成对差值。所有方法共享被抽取的 intent；不能分别对每个方法抽样，也不能把两个方法各自的 CI 相减当作差值 CI。[SciPy bootstrap 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)说明配对样本共用重采样索引；保留四层及其权重是本实验另外规定的采样设计。

单方法 CI 描述该方法成功率或均值的不确定性；配对差值 CI 描述同一题集构成下的方法差异。这里的 95% CI 是逐项区间，**不是三项比较同时覆盖的区间**，也不是经过 Holm 调整的区间。

二值结果全为 0／1，或所有 intent 的差值相同时，百分位区间可能退化为单点。仍展示原始计数并标注“重采样分布退化”；不能据此宣称真实成功率没有不确定性或证明等效。普通二项 Wilson 区间即使另列，也只能是明确声明假设后的单方法补充，不能替代分层配对差值区间；本版主表统一使用上述 bootstrap。

## 6. 次指标与诊断分析

BestGroupCov@10 和 CompleteMRR@10 默认报告均值、配对均值差和同一套 bootstrap CI，不扩展主比较族，也不为每个 $K$、标签或题型逐一寻找显著结果。

若另需检验次指标，应在查看独立评估结果前新增明确的假设与次检验族。本协议的可选方法是按 intent 成对交换方法标签、以均值差为统计量的双侧置换检验：采用 `permutation_type="samples"`，完整保留配对及层标签；不打乱 intent 间配对。无法穷举时预定 100,000 次置换、种子 20260929，并采用包含观测排列的保守 $p$ 值计算。该方法要求零假设下配对标签可交换，不能仅凭“指标非正态”断言适用；定义见 [SciPy 配对置换检验文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)。本版未激活这一附加检验族。

四个主层及交叉标签均报告实际样本数、成功率和差值方向。交叉标签子集可能重叠，不能相加当作新样本，也不能由“某层显著、另一层不显著”推断层间效果不同。

## 7. 样本规模与结论范围

80 个开发 intent 用于检查标注、记录、评分以及算法配置；先运行其中的小批即可发现流程错误，无需把一次技术试运行包装为确证实验。200 个独立评估 intent 是当前明确的计划规模，不是自动满足 80% 或 90% 功效的保证。

成功率的精度与方法差值的功效是不同问题。作为规划尺度，若暂按独立、同分布二值样本且成功率约 0.5 估算，200 题的普通 95% 比例区间半宽约 7 个百分点；每层 50 题约 14 个百分点。实际分层 bootstrap 区间须由新数据计算，不能把这些近似值当作已经得到的区间或预设验收线。

McNemar 的功效还取决于 $p_{10}$、$p_{01}$，即两个方向的不一致概率，而不只取决于 $N$ 或两方法各自的总体成功率。正式功效规划应声明有研究意义的最小差值和不一致率情景，并考虑三项多重比较；方法依据见 [Lachin, 1992](https://onlinelibrary.wiley.com/doi/abs/10.1002/sim.4780110909)。开发集可帮助提出情景，但小开发集中的效应估计不应被当作已知真值。

如资源只允许既定的 200 题，按原计划完成并报告差值与不确定性即可；不要求某方法必须提高，不把未显著差异写成没有收益，也不在看到评估分数后连续加题直到显著。

## 8. 缺失、错误与分母

每个预定的 intent × 方法单元必须保留状态，不能用过滤空值的聚合函数悄悄缩小分母。

| 状态 | 质量指标处理 | 必须保存 |
| --- | --- | --- |
| 成功完成且返回非空列表 | 依原始结果评分；不足 $K$ 条也不删题 | 实际返回长度、排名及完整性状态 |
| 成功完成且合法返回空列表 | answerable intent 的 CEGR、BestGroupCov、CompleteMRR 均为 0 | 完成状态与空结果 |
| 超时、崩溃、索引不匹配或记录不完整 | 标为失败／待修复，不伪装成合法空检索 | 错误、尝试次数、修复与重跑记录 |
| 方法未运行或模型不可用 | 显示“未运行”，不填 0 | 缺失原因与覆盖数 |
| 标注或资格缺陷 | 暂停受影响的正式计分；版本化修订后对所有方法一致处理 | 原始版本、缺陷与修订理由 |

主质量比较在修复后完整覆盖预定评估矩阵的可运行方法上进行；有失败的算法不得只用其成功完成的题报告正式质量均值。未修复的单元保留在矩阵中，受影响方法与比较显示“未完成”；已完整运行方法的结果须明确标为当前可用结果，不声称四方法矩阵已完成。没有重排模型时，R1–R3 可完成其预定分析，R4 和 C3 按 §3 标记。

如同时报告实际运行的交付成功率，可把最终错误导致无证据交付的单元记为失败，使用全部预定 intent 作分母，并单独标为运行可靠性统计。它不能冒充本文主质量指标，也不能通过静默重试抹去错误率。修复若改变算法或配置，须重新版本化受影响的整组运行；只修复执行环境时仍保留尝试链路。

## 9. 独立性与来源相关性

“不同 intent ID”不自动保证独立。应在划分时识别同一问题的改写、相同事实和共用关键证据的题族，防止它们跨开发／评估集泄漏；不得把改写换 ID 后计入 200 个独立 intent。

不同真实问题仍可能共用论文或证据，因而得分相关。记录来源集中度、每篇论文支持的 intent 数、共用证据族以及跨篇题的连接。主分析以 intent 为单位，其区间与检验的有效性以足够独立为前提，不把来源高度集中产生的 200 行当作等量独立信息。

在冻结标签时，另保存按共用证据／来源连接得到的依赖簇，作为预定敏感性分析：按整簇重采样，保留簇内全部 intent 和方法配对，再用原冻结题集的 $N_h/N$ 对本轮各层均值加权；权重不随簇重采样产生的层计数变化。簇跨越多个主层时不得拆开抽样；若重采样使某主层为空，记录无法估计的重复数并报告限制，不自行改用其他分母。报告簇数、最大簇规模，以及与 intent bootstrap 的差异。簇很少、单个来源连接成巨大簇或有效重复不足时，只报告描述性敏感性结果，降低总体推断强度，不输出看似精确的簇 CI。

## 10. 结果报告与冻结清单

正式报告至少包含以下内容：

- 数据及标注版本、开发／评估划分哈希、四层实际计数、独立 intent 和依赖簇说明。
- 每种方法的完成／空结果／错误／未运行计数，以及固定分母的 CEGR@10 成功数、率和 bootstrap CI。
- 三项预定比较的配对百分点差、CI、$b/c$、原始 $p$、Holm 调整后 $p$；未运行占位另注。
- BestGroupCov@10、CompleteMRR@10 和 $K=1,5,20$ 的诊断结果及适用样本数。
- bootstrap 次数、种子、软件版本、分位数计算方式和退化／无法估计的重复说明。
- 模型、索引、解析与切块版本；实际可用资产和所有协议偏离。

冻结前明确样本、指标、比较族、缺失规则、配置与推断范围。评估后新增的对照、题型切分或替代检验只能标为探索性；进一步确证须使用另行冻结的新评估数据。本文件规定方法，不宣称统计实现、标注或任何实测结果已经存在。

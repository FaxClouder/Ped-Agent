# 研究评估与审查验收标准

*项目正式内容的评估依据与人工审查边界 · status: current · 2026-10-04 起生效*

## 默认标准

**除非用户明确说明某个环节需要人工审查，否则，完成规定评估与验证的 Agent 评估就是本项目的正式内容，可据此验收、报告结果并推进后续环节。人工审查不是默认前置条件。**

本标准适用于 PedRAGent 与 PEARL 的标注、证据支持判断、实验评价、答案审查和阶段交付。不得因为没有人工参与，将已经完成的 Agent 评估降为“仅初步、非正式、尚未完成”，或自行增加等待人工确认的门槛。

只有用户明确指定需要人工审查的环节，才将人工审查作为该环节正式验收的必要条件；其范围按用户说明执行，不自动扩展到其他环节。旧计划、方法草案或工具流程中的人工审查默认要求，与本标准冲突时，以本标准及用户最新指示为准。

## 正式验收仍须有实际证据

正式采用 Agent 评估不免除实验与质量验证。评估须基于实际输入、实际证据和已执行的判断；记录模型、配置、版本、评审依据及结果来源，按具体实验协议完成必要的评分复算、输入输出核验和可复现性检查。

独立复核、盲化、评审一致性检查或确定性参考样例，可由 Agent 或程序执行。不得把缺失证据、未运行实验、未完成裁决或未知项直接写为成功，也不得用引用存在性检查代替语义支持判断。对评审分歧应记录依据并裁决；仍无法确定的内容保留未知状态并报告其影响。

## 验收状态与审查来源分开记录

| 信息 | 解释 |
| --- | --- |
| 正式项目内容 | 按本标准及该实验的验证要求验收的评估、分析和阶段交付 |
| Agent 评估 | 实际评审来源；默认可构成正式项目内容 |
| `human_verified=false` | 未实施人工核验的事实记录，不表示非正式或阶段未完成 |
| `agent_reviewed_preliminary` 等旧字段 | 保留历史版本的原始标签；在本标准下，不单凭该字段否定已完成评估的正式验收 |
| 开发、独立评估、探索性分析 | 实验用途和统计主张范围；与是否正式采用 Agent 评估是不同维度 |

正式采用 Agent 评估不等于宣称有人工核验，也不将开发结果自动变为独立评估结果。评审来源、样本局限、未知项和统计不确定性仍如实报告；这些信息本身不构成等待人工审查的要求。

## 现有 Retrieval 交付与后续层

已完成并通过既定验证的 [Retrieval 阶段 D 交付](../experiments/pearl-retrieval-eval200-20261003/evaluation-analysis-2026-10-03.md)，按本标准作为正式 Agent 评估内容验收。无需追加人工核验才能推进 Layer 2–4；后续层仍须分别实际执行并验证，不能由 Retrieval 完成推定完成。

原 Gold、配置、排名、输出、冻结报告及其哈希和 provenance 保持原样。本标准通过当前文档说明验收口径，不追改历史实验字段、评分或发布清单。此前清单中的工作区文档哈希是交付时快照；本次规则更新不追改该快照。

后续报告应清楚说明“正式 Agent 评估”以及实际审查来源；只有用户明确要求且实际完成了人工审查，才记录相应人工核验事实。

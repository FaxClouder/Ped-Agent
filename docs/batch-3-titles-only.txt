## 搜索建议

1. Web of Science（优先）- 可获取分区、JCI、引用量
2. Scopus（补充）
3. Google Scholar（快速定位）
4. 期刊官网直接搜索

✓ 作者姓名和单位

✓ 期刊名称和卷期
✓ DOI
✓ 中科院分区
✓ JCI指标
✓ 引用次数
✓ PDF下载链接

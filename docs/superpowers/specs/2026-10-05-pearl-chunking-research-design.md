| 问题 | 假设，不是结论 | 对照及反证条件 |
| --- | --- | --- |

| RQ3 重叠是否仍值得？ | 重叠可能改善边界证据，但也可能与恢复重复 | 固定 core，0/10/20%；若收益不足而重复和成本上升，则不支持采用 |

## 5. 切片与恢复策略定义

### 5.1 四种正文边界

| ID | 策略 | 必须保持的定义 |
| --- | --- | --- |
| C1 | Fixed-token | 同文献规范化正文按真实 tokenizer offsets 切分，保留尾块与可逆来源 |
| C2 | Recursive-boundary | 贪心组合完整段落；超长段拆句；超长句才按 token 回退；允许跨小节 |
| C3 | Structure-aware | 小节内使用与 C2 相同规则，不跨小节，不为凑长度合并短小节 |
| C4 | Adjacent-semantic | 连续句子向量距离决定边界，不合并不连续文本，不生成或改写内容 |

L＝256/384/512 BGE tokens，是 core 上限，不是实际均长。初轮 overlap=0、prefix=M0。统一文献边界、表格屏障、标题包含规则与可检索内容范围；正文和表格统计分开。

C4：固定 BGE-M3 编码同一分句器输出；距离为 `1-cosine`；阈值为无标签冻结语料有效相邻距离的90百分位，冻结分位数算法。达到 `floor(0.5L)` 后遇距离超过阈值可切；加入下一句超过 L 则先切；长句使用 C2 回退，尾块保留。不得用 query/Gold 校准阈值，不因开发成绩差而无限搜索。

### 5.2 恢复与父层级

| ID | 策略 | 规则 |
| --- | --- | --- |
| P0 | Child only | 命中 source_text，经来源去重后输出 |
| P1 | Paragraph window | 命中原文段落加前后各一个段落；每侧不越所属小节；不是相邻 chunk |
| P2 | Source parent | 使用一次冻结、独立于 child 切法的公共父层级 |

父层级按小节内连续完整段落组织，默认上限1536 BGE tokens，过长单元按句子处理；该值是预设参数，不是最优结论。若已有符合要求的公共父图，E0 核验后可复用并登记实际规则。跨父 child 保留多父映射及上下文放大率。

overlap 配置的恢复从 core_spans 定位，再与已命中的合法 overlap 来源取并集。所有配置共享表格快照；本轮不做表格—正文专属恢复。表格专项后置。

### 5.3 重叠与前缀

E2 固定核心块，附加不超过 `floor(rL)` 的连续原文前文，r＝0/0.1/0.2；优先整句，超长句允许可追溯 token 后缀。不跨文献/表格屏障，C3 不越小节。分别保存 core_spans、overlap_spans、实际比例。附加后可能超过 L，不能声称最终输入等长。

M0 为 source_text；M1 为原文论文标题＋章节路径＋source_text。前缀默认最多64 BGE tokens，保留标题与叶子小节优先，再补祖先层级；记录截取规则与来源。它同时作用于 BM25、dense、rerank，前缀本身不参加 Layer 1/2 证据支持判定。生成上下文来源头格式保持相同。

## 6. 公共协议与数据契约

### 6.1 基线身份

H0 是历史快照，只读保留；B0 是当前正文切块方法在本轮公共协议下的重跑。E0 必须解析其真实算法、长度单位、overlap、parent 和表格行为。B0 不强制改成 O0；其原有重叠如保留须明确登记，不能解释为纯边界对照。12格内部才固定 O0/M0。

B0 与某格仅在所有相关配置和输入一致时可复用并保留别名。B0 统一表格、M0、检索链和评价；与 H0 的差异单列。E3 的 B0 使用公共恢复规则，不能混入历史私有 parent。

### 6.2 来源与评价隔离

来源身份至少含 doc_id、source_version、element_id、字符区间或表格单元格位置及坐标类型；不连续内容用多段映射。页码和 hash 不能单独替代来源位置；无法回映 PDF 坐标时仅声明解析文本定位。

Gold requirements 绑定原文事实、必要条件和允许证据组，组内 AND、组间 OR。支持只能由实际保留文本确定；同论文或关键词命中不算支持。完整已核验锚点可确定性复用，其他情形语义审查并保留 unknown。发现等价证据后版本化共同映射，对全部受影响配置重算。

Gold/参考答案只在离线评价侧使用，不进入 chunker、语义阈值、query、恢复、预算分配和生成。正文切片、父图与来源映射先建立，再作离线支持判断。

### 6.3 检索、预算与面板

固定 BM25、BGE-M3、RRF、reranker 及候选深度；参数从实际冻结资产读取，不猜。主比较 R4，对 RRF Top-100 重排，保存所有中间排名。每个新索引真实检索，不能跨切片复用旧排名。

| 面板 | 输入 | 用途 |
| --- | --- | --- |
| Layer 1 固定K | 原始 child Top-1/5/10/20 | 主报 CEGR@10；父文不回填 |
| fixed_budget_main | R4 Top-100 依序组装到4K/8K | CGC及 E5 的实际生成输入 |
| seed10_diagnostic | 相同 R4 Top-10，保存 raw/expanded/final | 隔离展开挽回与预算损失；不与主面板差量混算 |

组装统一按排名、按真实来源区间去重、展开内部按来源顺序、首次溢出保留最大合法前缀并停止。不同文献同文句不合并；截断同步更新来源区间。预算按完整序列化 context 重新计数，包含标签和来源头，不含系统提示、问题和输出预留；完整请求另检模型上限。

切片长度和公共预算使用固定 BGE tokenizer；provider usage 另列。检查 embedding 和 query+reranker 完整输入，避免只对某策略静默截断。相同K不代表相同计算量。

## 7. 实验矩阵、筛选与统计

| 阶段 | 范围 | 正式输出 |
| --- | --- | --- |
| E0 | 资产、协议、5–8个固定分层意图冒烟 | inventory、来源登记、resolved manifest、调用台账、契约核验 |
| E1 | 12格＋必要时B0，80题，P0×4K/8K | 新索引、逐题排名、Layer 1–2；不生成 |
| E3 | B0＋最多2候选，P0/P1/P2×两预算，最多18单元 | 主面板和种子诊断，最多2880份上下文记录，非独立问题数 |
| E2 | 最多2个core候选×三档重叠 | 0%等价复用，最多新增4索引；P0及一个预先固定恢复策略 |
| E4 | 首选1个完整候选M0/M1，必要时第2个 | 检索表示消融；随后最终组合完整重跑Layer 1–2 |
| E5 | 最多3配置×80意图×3真实生成，主预算4K | 最多720答案，Layer 3/4、重复波动和成本；裁判另计 |
| E6 | 单独决定的新封存测试或旧200回归 | 冻结后验证，禁止据此继续调参并覆盖原结果 |

E0 冻结候选规则：默认按4K CGC确定完整率降序、再按CEGR@10、实测检索延迟较低、config_id排序处理完全并列。unknown 的可能界足以改变入选时先审查或将候选保持待定，不把上界当成绩。第一个候选按该顺序；第二个可选不同策略家族作机制对照，须标明该目的，不称第二优。没有非重复有效候选时缩减。

E3 选择后续消融恢复策略时仍按4K完整性、成本规则，在 E2 前冻结。E2/E4 的组合效果以最终重跑为准。E5 不根据某一次答案波动重新挑配置；若产生新研究想法，登记新开发迭代。

主指标：Layer 1 CEGR@10；Layer 2 CGC@4096/8192；Layer 3 Strict，辅以AC、Claim Coverage、Integration；Layer 4 Faithfulness、引用P/R及必要结论不能补全时的行为。不得用任意加权总分代替。

统计单位是 intent，重复先在意图内取均值，再跨意图汇总；80×3不等于240个独立问题。题型分层配对 bootstrap 默认10000次、种子20261005，报告相对B0差值及95%区间。三值支持另报确定下界、可能上界和unknown覆盖，可能界不是置信区间。预设确定二值面板可用精确McNemar与Holm；三次均值不能直接用于二值检验。开发选择偏差不会被多重校正消除。

## 8. 生成、审查、失败与成本

生成仅见 query、真实 final context 与冻结提示，模型/API实际标识须预检；不直接沿用历史名称假定可用。每个请求保存完整hash和replicate_id，三次必须真实调用；完全相同请求可以共享同三次真实记录，不能复制一次伪造重复。配置间交错调用，固定并发；无限重试禁止。

审查复用现有量表、校准及保存产物独立复算机制；方法、排名、旧分数对语义审查隐藏。当前请求没有指示本 session 委派研究；未来若用独立 Agent 盲审，须按执行环境授权使用隔离上下文并如实记录身份与局限，不以同一作者自检冒充独立审查。

失败按已核验证据归因：F0源缺失、F1切块/索引遗漏、F2候选不足、F3排序损失、F4恢复不足、F5预算损失、F6证据充分但答案失败、F7支持/引用/条件错误、FU未决。Top-100 unknown不能证明索引无证据。

成本分一次性来源处理/切片/句向量/建库与逐题检索/重排/组装/生成；裁判是研究成本，单列。API失败保存原错误、有限重试、实际用量，不静默从分母删除。

不默认开启：LLM切片、摘要前缀、命题抽取、Late Chunking、新解析器、query改写、智能预算分配、答案修订、动态Agent、表格专项或新的200题运行。新增服务、私有文献上传、超过已授权额度均不由本计划自动授权。

## 9. 交付与结论边界

必须交付真实逐题结果、原文映射、最终上下文、参数和代码身份、检查记录、复现命令、成本、unknown/失败及差异案例。推荐必须给出完整 C/L/O/M/P/B 配置和适用题型，说明是否仅为开发选择。

主表至少包括切片画像、检索完整性、恢复×预算、答案与可靠性、成本五部分。图只从真实保存数据生成；4K/8K两点不能声称连续响应曲线。无差异、无提升和复杂方法退化均是可验收结果。

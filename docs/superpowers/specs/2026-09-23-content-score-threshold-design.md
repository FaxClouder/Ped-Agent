# 文献全文评分门槛调整设计

_将现有五批全文评判按“高于 65 分即满足内容分数要求”重新判定 · status: plan_

## 目的与边界

现行文献入库标准及离线治理契约把全文质量最低分设为 80。五批 PDF 已按同一套
30/30/20/10/10 评分维度完成评判；本次只修改分数门槛及其派生状态，不重打分、
不修改 PDF，也不把“内容分数通过”等同于正式入库。

## 判定规则

- 严格使用 `total_score > 65`：整数分 66–100 通过，65 及以下不通过。
- 保留五项原始评分与总分，重新计算 `screening.csv` 的全文筛选结果和相关决策标记。
- DOI/PDF 身份、主题范围、撤稿状态、期刊分区、WoS/Scopus 引用快照、授权、
  主题标签和 A/B/X 等级仍是独立门槛。存在独立问题的记录可通过内容分数门槛，
  但必须继续保持待核实或候选状态，不得自动转成正式收录。
- 在本次 108 条记录中，预期 104 条超过 65 分、4 条未超过；其中正好 65 分的
  记录仍不通过。这个数量是迁移前的核对基线，实际写入后须重新统计验证。

## 变更范围

1. 同步人工标准 `memPed/knowledge/collection_standard.md`、机器可读规则
   `memPed/knowledge/literature_quality_rules.yaml` 和离线治理契约
   `Knowledge-Base/src/ped_knowledge/governance/contracts.py`，并补上 65/66 边界测试。
2. 按 DOI 对五批 `screening.csv` 重新计算由分数派生的字段；对身份、范围等独立
   疑点保留单独的待核实决策，避免旧的 `below_80` 标记或一律放行。
3. 不覆盖五份原始 PDF 评判报告；增加注明规则变更日期、旧新门槛和重新统计结果
   的补充记录，使历史判断与当前判断都可追溯。
4. 不在本次生成正式技术 Manifest，不分配 A/B/X 等级，不执行导入或索引发布。

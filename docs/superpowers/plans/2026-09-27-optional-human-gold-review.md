# 可选人工 Gold 审查计划

*仅在未来研究明确要求人工核验标签时启用 · status: plan*

当前文献 RAG 开发集采用独立 agent 复核结果进行探索性研究；20 个 intent 均可用于开发集检索与失败分析。人工复核不是当前实验、P1 对照或继续研究的前置门槛。是否开展人工 Gold 审查应由未来论文或外部评审对标签来源的要求决定。

若启用，审查者按 intent 核对中英语义、每个原子事实与证据组的映射、来源 PDF 哈希和更细 locator、数值单位及有依据的容差、等价表述与无依据推断边界。保留有争议的原文值并记录裁决，不把 agent 的判断改写成人类判断。另建版本化标注包和决定记录，注明审查者、日期及输入哈希；只对实际经人类逐项核验的记录设置 `human_verified=true`，不得覆盖已有 agent 复核或研究输出。

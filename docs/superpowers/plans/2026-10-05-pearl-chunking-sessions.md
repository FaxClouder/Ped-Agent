## 10. 每阶段统一交接格式

在实际run目录新增 `handoff.md` 和 `delivery-manifest.json`；本文只是定义字段，不创建虚假完成清单。

| 字段 | 要求 |
| --- | --- |
| stage/status | 当前阶段；planned/built/retrieved/assembled/generated/scored/failed/blocked/skipped分别记录 |
| inputs | 上阶段manifest路径与hash，协议、代码dirty快照、数据/模型/映射身份 |
| outputs | 实际存在的文件、SHA、数量、索引位置和恢复方法 |
| commands/checks | 实际命令、返回码、日志、测试与独立复算结果 |
| counts | planned/completed/failed/unknown/pending-review及复用数量，分母说明 |
| decisions | 已冻结选择、依据、协议偏差、影响及重跑范围 |
| budget | 本阶段与累计生成/裁判/重试、usage、授权剩余；未知费用明确标记 |
| next | 下一session唯一入口、前置条件、阻塞和禁止跨越的范围 |

下一session先校验manifest与当前文件hash；漂移时定位影响，不自动重写历史身份。关键来源无法恢复、输入不对称截断、Gold泄漏、缓存串用或额度不足只阻止受影响阶段。无提升不是阻塞理由。
